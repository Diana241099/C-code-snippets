# C Code  

A collection of simple C programming code snippets.

## How to Run in Bash

1. **Compile:**
   ```bash
   gcc filename.c -o program
   ```

2. **Run:**
   ```bash
   ./program
   ```


## How to run in Powershell

1. **Compile:**
   ```powershell
   gcc filename.c -o program
   ```
2. **Run:**
   ```powershell
   .\program
   ```
